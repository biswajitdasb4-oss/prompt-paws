How it works

Four small parts, each with one job.

  1. Hooks report

    A Claude Code plugin adds hooks. On each event, a short shell script writes the session's state to a file: needs you, your turn, or working.

  2. The app decides

    A Swift app reads those files about three times a second and picks what the panda does next: walk, sit, wave or cheer.

  3. three.js draws

    The panda is a rigged 3D model with 12 moves, drawn in a see-through window that floats above every app.

  4. One click returns you

    A short AppleScript selects the session's Terminal tab, so you land on the exact session that is waiting.

On this page, the panda, its moves and its bubble come from the app's own drawing code. Claude, the Terminal and the browser window are pretend, so you can try it without a Mac.
